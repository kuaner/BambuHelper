# BambuTUTK experimental transport

Adapted from ClusterM/open-bamboo-networking (AGPL-3.0), commit 2c17a64b5075dc98af977b098d12dd3c39a9c670.
Source: https://github.com/ClusterM/open-bamboo-networking

The TUTK transport and FEC implementation retain upstream licensing.
This module adds an ESP32-P4 mbedTLS backend, bounded snapshot transfers,
and PSRAM allocation. Firmware linking this module must satisfy AGPL-3.0;
the rest of the repository retains its existing notices and licenses.

No application private key, account token, or device credential is included.
